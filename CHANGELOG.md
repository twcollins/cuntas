# Changelog

## Unreleased

Several households on one device: each household is stored separately, with a switcher at the top of the sidebar and a Households screen to add one (new, demo, or by invite link), switch, remove it from the device, delete it on the server, and manage who can open it, with invites that set the role. An Account & sync screen replaces the server card in Data & sync (now Settings): sign in or create a sign-in with a passkey, open server households on this device, and sync the open household; the server address comes from `VITE_API_URL`. Signing in no longer replaces local data with the first server household; every replacement asks first. Onboarding adds "I already use Cúntas", and an invite link works on a device with no household. A Guide page gives a short tour of every feature, and the light/dark toggle moves from the sidebar to Settings. On-device storage changes to one IndexedDB entry per household with no migration (not yet released), so existing local data is reset. Playwright covers two households on one device and the onboarding sign-in card.

AIB import now recognises the current-account CSV export, which has one Description column instead of Description1–3 and two-digit years. Its zero-amount follow-on rows (ATM location, card time, references) are folded into the transaction above, and so is the end-of-day balance they carry. When no bank preset matches a CSV, the column mapper now guesses columns from the header names instead of taking the first three columns in order.

## 0.2.0 — 2026-10-23

Completes the phase 3 and 4 features. Self-employed tax: Class S PRSI applied month by month across a rate change, and a Form 11 estimate with preliminary tax on the 90%, 100% and 105% bases, balance due, deadlines and a monthly set-aside, which the engine asks self-employed households to plan for. UK: student loan plans 1, 2, 4, 5 and postgraduate in take-home pay; the pension annual allowance with taper, carry forward and MPAA; and a Scottish income tax sub-pack. A payslip check for Irish payslips (emergency tax, credits or band not allocated, USC band, PRSI) and UK ones (tax code, NI, student loan). Recurring-bill detection with price rises plus an Irish and UK bill calendar; a retirement projection with Irish and UK State Pensions in real terms across three scenarios; an after-tax wrapper comparison; and a residence what-if driven by relocation notes in the cross-border pack. HSBC UK CSV import (two layouts). Light, dark and system themes. A server admin role (granted only from the database owner's shell) to create, rename, suspend and delete households and manage members, plus owner-level member management; migration `0002_admin.sql` adds `users.is_admin`, `households.suspended_at` and invite roles, guarded by a trigger so the API role cannot grant admin. Capacitor 8 iOS and Android projects, with API options for native origins and cross-site cookies. The dataset gains payslips, bills and new member fields, all defaulted so 0.1 exports still load.

## 0.1.0 — 2026-10-22

First build from `docs/SPEC.md` (phases 0–2, with parts of 3 and 4). Versioned IE and UK rule packs with golden tests; the next-step engine for the seven flowchart steps; bank-file importers with ten presets; a local-first React PWA covering ledger, budgets, debts, goals, pensions and a tax centre; and an optional self-hosted stack (Hono API, pg-boss worker, Postgres with row-level security) for passkey sign-in, household sharing, encrypted sync, ECB rates and PSD2 bank sync via Enable Banking.
